ytdlp-FFmpeg-GUI · 架构总览
与代码同步｜统一列表 + 元数据先行 + 下载/转码/合并三能力动作｜不做流水线编排
一、主流程：添加 → 解析元数据 → 统一列表 → 能力动作
① 添加
粘贴 URL（B站/抖音/YouTube/X…）
添加本地文件 / 目录（拖拽或选择）
→
② 解析元数据（先行）
URL：yt-dlp -j（标题/时长/缩略图/清晰度列表）
本地：ffprobe + volumedetect（分辨率/编码/帧率/音轨/封面/音频音量）
下载完成产物同样本地解析（MD-06）· 失败分类提示 + 重新解析
→
③ 统一列表 · 待处理
同一份列表，勾选即可批量操作
工具栏右侧垃圾桶图标清空列表（无状态筛选）
→
④ 能力动作（用户触发）
下载 · 转码 · 合并（行内或批量按钮）
执行中显示进度，完成后回到列表
二、统一列表 · 条目状态机（MediaItem）
解析中 已就绪 下载中 后处理中 转码中 合并中 已完成 失败 已取消 需要登录
来源（站点/本地）显示在名称副行，不单独设列；解析结果用于画质列展示、下载格式列表、转码音频增益依据与合并参数对比。
三、三大能力（独立动作，不做自动编排）
下载（yt-dlp）
· 四级格式回落 + 排序串，MP4 容器统一、同名不覆盖
· 下载后处理：画质上限 + 音量归一化 + 封面/元数据嵌入 + 产物本地解析（MD-06）
· 内置登录（WebView2：顶部中心"登录完成"按钮 + SPA 800ms 保活，走系统代理）、站点分流代理（白名单）
· 时间范围下载、播放列表展开平铺、仅音频提取（mp3）、JS 运行时显式传 deno
转码（ffmpeg）
· 编码器：auto（QSV → libx265 兜底）/ libx265 / NVENC / AMF（探测标注），硬编失败自动回退 libx265 重试一次
· 手动旋转 / 分辨率封顶（保比、不放大、偶数对齐）/ 码率封顶 / 按解析音量增益（max_volume）
· 封面：保留（按封面流索引映射原样 copy）或关闭
· 碰撞安全命名（自动递增 / 跳过）；全部音轨 + hvc1 + faststart
合并（ffmpeg）
· 勾选多条目 → 面板排序 → 按序拼接（整批作为一个作业占一个并发额度）
· 模式A 同参直拼（编码/分辨率/帧率/音频/采样率 + extradata SPS-PPS 一致，零重编码）/ 模式B 异参先统一转码再拼（差异预警）
· 输出 MP4/MKV；直拼时视频 copy，异参统一走 H.265
· 可选音量归一化；产物作为新条目回到列表
四、工程架构（全新脚手架，核心层与界面分离）
界面层（UI）｜顶部输入区（URL/添加文件/目录）· 批量操作栏 · 统一媒体列表 · 合并面板 · 设置弹窗 · 底部状态栏（原生 HTML/CSS/JS）
命令与状态层｜前后端命令桥接 · 全局状态（统一列表数据）· 并发队列 · 登录窗 · CLI 入口/单实例转发
列表模型MediaItem、状态机、筛选视图、历史、队列持久化
元数据解析URL 解析（yt-dlp -j / --flat-playlist）、本地与下载产物探测（ffprobe -show_data + volumedetect）、失败分类
下载能力参数构造（格式回落/排序）、子进程运行、进度解析
转码能力编码器选择与失败回退、旋转/分辨率封顶、码率/增益/封面流映射、碰撞命名
合并能力参数与 extradata 对比、同参直拼 / 异参统一后拼、输出封装、可选音量归一化
探测 / 配置历史 / 站点Cookie / 依赖定位（工具链版本管理）（基础支撑）
存储约定全部文件在 exe 同级（绿色便携）：config/（config.json · history.json · cookies/ · cache/thumbs/）· temp/（任务私有目录，含合并中间产物）· tools/（托管工具链）
五、打包与交付（Windows 服务器编译打包）
build.ps1（pwsh 7：核心层单测 → Clippy → cargo audit（信息性）→ release 构建）｜CI：GitHub Actions Windows 服务器（windows-latest） —— build.yml（单测 + 核心层与 GUI crate Clippy(-D warnings) + cargo audit + 构建校验 + 上传产物）、release.yml（tag v* 构建 + 打包 zip + 发布草稿）｜交付物：仅单 EXE、无安装包（不做 NSIS，绿色便携）｜Linux 环境打包参考 scripts/cross-build/README.md（cargo-xwin/zig 交叉编译，本地备用通道）
