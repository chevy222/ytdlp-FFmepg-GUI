ytdlp-FFmpeg-GUI · 主要功能流程图
与代码同步 ｜统一列表即工作台 + 元数据先行 + 下载/转码/合并三能力动作 ｜无流水线编排 ｜绿色便携单 EXE（全部文件在 exe 同级）
一、主流程：添加 → 解析元数据 → 统一列表（已就绪）→ 能力动作 → 已完成
① 添加
粘贴 URL（B站/抖音/YouTube/X…，含合集链接）
添加本地文件 / 本地目录
CLI 入口（--url 可重复）
→
② 解析元数据（先行）
URL：yt-dlp -j → 标题/时长/封面/清晰度清单/格式列表；合集则展开每集平铺（DL-09）
本地：ffprobe + volumedetect → 容器/分辨率/编码/帧率/音频/音轨数/最大音量/时长/大小/封面
下载完成产物同样本地解析（MD-06）
→
③ 统一列表 · 已就绪
同一份列表，勾选即可批量操作
URL 解析完 5s 倒计时自动下载（点画质下拉取消）
工具栏右侧垃圾桶图标清空列表（无状态筛选）
→
④ 能力动作（用户触发）
下载 · 转码 · 合并（行内或批量，见下节）
执行中显示进度，完成后产物回列表再解析
→
⑤ 已完成
状态"已完成"（不强制接着转码）
可继续转码/合并/打开目录/删除
二、三个能力动作（作用于条目，不做流水线编排）
下载（URL 条目 · yt-dlp）
格式选择：画质/格式 modal（容器/分辨率/编码/码率/音轨…）
时间范围：行操作"剪辑"设起止 → --download-sections
参数：--cookies（config/cookies/，导出到任务私有目录）、代理、并发分片、重试、仅音频、嵌入封面/元数据
输出：默认桌面（可配）→ 文件名模板（纯标题/标题+ID/日期-标题）
后处理：音量归一化（通用）→ 产物本地解析回列表
播放列表：默认开关 → 展开每集平铺
转码（本地/产物条目 · ffmpeg）
编码器协商：auto = QSV → libx265 兜底；可强制 NVENC/AMF（探测标注）
TC-16：硬编失败自动回退 libx265 重试一次
参数：分辨率上限（长/短边）、码率封顶、x265 CRF 固定 23、旋转（手动）、音量增益上限、保留封面、mp4 hvc1 +faststart
文件名模板共用下载段；碰撞 auto_inc / skip
进度：-progress pipe:1；取消 = kill_tree + 删残留
合并（多选条目 · ffmpeg）
多选 → 顶部批量栏"合并"（单条无合并按钮）
面板：顺序上移/下移/移除、容器（MP4/MKV）、编码器、文件名
模式 A 同参直拼：编码/分辨率/帧率/采样率/extradata(SPS-PPS) 一致 → concat 零重编码
模式 B 异参统一：逐段 H.265 转码后直拼（参数差异预警）
MG-05：合并后音量归一化（开关默认跟随通用）
temp/merge_<uuid>/ 私有目录，结束清理

四、异常与兜底分支
解析失败：分类提示（B 站 412 → 放 cookie；YouTube 403 → 检查 deno/代理/cookie；X 强制登录）→ 失败状态可重试 / 去登录
下载失败/取消：取消 kill_tree + 删除 temp 残留；失败保留输出判断，产物回列表按 MD-06 重解析
登录（内嵌 WebView2）：需要登录 → 去登录 → 内置浏览器登录 → 顶部中心"登录完成"按钮触发 cookie 保存（YouTube SPA 每 800ms 重注入按钮兜底）→ 回列表重试
硬编失败：TC-16 自动回退 libx265 重试一次（日志说明）；合并同参判定含 extradata(SPS-PPS)，不符则走统一转码避免花屏
五、目录与存储约定（全部在 exe 同级，绿色便携）
exe 同级/
├─ config/　config.json 用户设置、history.json 列表/队列/条目日志、cookies/<host>.json、cache/thumbs/<条目id>.jpg 封面缩略图
├─ temp/　任务私有目录 temp/<任务id>/（导出的 Cookie）、temp/merge_<uuid>/（合并中间产物）、temp/tool_dl/（工具链下载暂存）
├─ tools/　托管模式工具链（yt-dlp / ffmpeg / ffprobe / deno）
下载/转码/合并输出 → 默认桌面（可配默认输出目录）；JSON 原子写（临时文件 + 单次 rename 覆盖），损坏备份后回退默认；日志按条目查看（弹窗只显示该条目，无全局日志页）。
六、设置体系（统一弹窗六个分组，路径输入框、站点 Cookie/分流加+-列表）
依赖
ffmpeg/ffprobe/yt-dlp/deno 路径（默认 PATH，可输路径）；下载与更新按钮：yt-dlp（yt-dlp/yt-dlp 发布）、ffmpeg+ffprobe（BtbN/FFmpeg-Builds）、deno（denoland/deno），经 SHA-256 校验后原子激活到 <exe 同级>\tools\
网络
代理地址输入框 + 常用代理工具下拉；站点分流加+-列表（仅勾选的站点走代理，其余直连）
Cookie
列出 config/cookies/ 下已保存站点（数量 + 最长有效期），可删除
下载
并发分片、重试、仅音频、播放列表默认、嵌入封面/元数据、文件名模板（下载/转码/合并共用）
转码
长边/短边上限、码率封顶、默认编码器（auto/libx265/NVENC/AMF，探测标注）、QSV low_power、保留封面；x265 CRF 固定 23
通用
默认输出目录（桌面）、碰撞命名策略、音量归一化（下载后处理与转码共用）+ 增益上限、并发任务数（全局共享，默认 3）；启动时检查更新 / 历史上限 / 清理解析缓存三项在配置中保留但尚未接线
